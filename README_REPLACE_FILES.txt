# Обновлённые файлы

Замените в репозитории файлы по тем же путям:

- `css/style.css`
- `js/main.js`
- `js/picture-shooter.js`
- `js/type-preposition.js`
- `assets/images/background_space_playroom.png`

Изменения:

1. Новый фон отображается на главной странице и внутри каждой игры.
2. В Picture Shooter:
   - Easy — 3 картинки;
   - Medium — 4 картинки квадратом 2×2;
   - Hard — 6 картинок.
3. В Picture Shooter показывается полная фраза: `under the table`, `next to the sofa` и т. д.
4. В Type the Preposition на Easy и Medium нужный предлог автоматически озвучивается и есть кнопка повторного прослушивания.

5. Из Sentence Builder удалено задание `between the table and the box`, потому что для него нет полной озвучки объекта. В этой игре теперь 7 раундов; в Picture Shooter и Type the Preposition остаётся 8 раундов.
